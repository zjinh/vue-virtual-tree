## 证据边界

性能是本机指定输入测量，非任意业务全场景保证。自定义slot保持旧范围，不承诺同样DOM降幅。折叠树内存基本持平。宽树级联仍约1.2秒，没有宣称优化。最后严格版滚动样本Vue3 p95 735ms/2长帧，Vue2 p95 1952ms/2长帧，非全程无卡顿。

无新增业务 API 或运行时依赖。版本 2.0.1 按仓库 GitHub Release 触发 npm 发布的流程发布。
