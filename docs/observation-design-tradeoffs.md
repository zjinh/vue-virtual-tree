# 树观察的内存与兼容边界

用户明确要求严格兼容。当前采用原版四屏行观察范围、内置内容一屏渲染范围；自定义插槽保留四屏内容，维持原版局部状态及生命周期。普通Node字段保持原版描述符、继承和删除/重定义语义。

全树观察方案已撤销。它曾使Vue3五万折叠树挂载堆由约39MiB增至133MiB，并扩大窗口外/折叠/过滤节点通知，抑制原版滚动复用通知。原版实测并不提供全树事件流或所有raw数组修改统一同步。因此这些新增行为不能作为性能优化的兼容要求。

浅层数组代理、实例访问器和自定义Proxy原型没有证明兼容及净内存收益，均未采用。保留原版行watcher也保留Vue2/3浅观察差异，结构更新优先使用公开方法。性能与最终验证见performance-2026-10-27.md，过程证据见repair-status-2026-11-11.md。
