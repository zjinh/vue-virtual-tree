# 兼容性修复记录

本次优化以 ae50f54 为基线，按严格兼容要求验证 Vue 2.7 和 Vue 3。最终性能及测量边界见 [性能报告](performance-2026-10-27.md)，验收范围见 [提交验收](submission-audit-2026-11-11.md)。

## 已撤销的方案

- 全树观察扩大了原版窗口外、折叠和过滤节点的事件范围，并增加折叠树内存。恢复原版四屏行观察及位置复用。
- 将 Node 内部字段设为不可配置会改变删除和重定义行为。保留普通字段描述符。
- 在公开 updateChildren 中按内容相同提前返回，会改变 childNodes 数组身份。恢复原版数组替换行为。
- 行 children watcher 跳过已同步节点的重建，会吞掉滚动时的外部数组引用通知；null 到 null 位置复用后也会误吞显式 children=[]。恢复原版 watcher，放弃零展平滚动。
- 自定义插槽缩小窗口会改变生命周期和局部输入状态。保留旧四屏渲染范围，仅默认内容采用一屏缓冲。

## 保留的回归保护

公开字段描述符、同步选择传播、children 数组身份及外部 watch 通知、同值行复用、动态事件监听、原始 children 浅观察、lazy、重入、卸载清理、默认窗口覆盖和自定义插槽输入状态均有回归覆盖。

验证包括 69 项模型测试、双 Vue 各 131 项组件测试、4080 组模型差分、双 Vue 窗口事件及数组身份差分、四个 Vue 版本打包安装、类型与发布产物检查。滚动长帧和构造/过滤/选择递归仍属于已知限制。
