# 性能改造与验证记录

更新：2026-11-11。基线 ae50f54，分支 codex/tree-performance。用于 2.0.1 发布。严格兼容最终版已撤销滚动 watcher guard；最终独立审查未发现新的确定阻塞，确认公开方法与watcher恢复。

## 实现与兼容范围

内置行实际渲染上下各一屏，行观察保留原版上下各四屏及位置复用。移除全树观察，恢复原版 check-change 和 children 浅观察语义，包括 Vue 2/3 原地数组修改差异、滚动复用和整体 data 替换时可能出现的通知。自定义插槽保留原版四屏渲染范围，避免更早卸载内部组件或丢失局部状态。

保留初始化跳过重复查找、key映射查询、check事件查询复用、窗口截取后创建索引、迭代展平和同值type字符串复用。Node字段描述符保持原版；_loadVersion不可配置优化已撤销。公开updateChildren和行children watcher均保持原版，包括滚动复用时替换公开childNodes数组并通知外部watcher。此前跳过重建的guard会吞掉这些通知，也会误吞null到null复用后的显式children=[]，已整体撤销。
